Minha irmã queria jogar alguma coisa comigo e não sabia o quê. Aí eu vi um cara que tinha feito um jogo na web com o celular de controle e resolvi fazer o nosso. O jogo roda no PC e aparece na TV, e cada pessoa usa o próprio celular como joystick pelo Wi-Fi de casa, sem instalar nada. São 80 minijogos para 2 a 4 pessoas, feitos com three.js e um servidor Node que conversa com os celulares por WebSocket.

[Baixar para Windows](https://github.com/hugh514/minijogos-de-sofa/releases/latest) ou [ver o código](https://github.com/hugh514/minijogos-de-sofa).

### No dia a dia

Escrevo TypeScript quase o tempo todo: React e Next.js no front, NestJS no back. Uso Go quando o serviço precisa aguentar carga gastando pouco. PostgreSQL e Redis entram em quase tudo, Docker e GitHub Actions colocam no ar e Playwright garante que a tela não quebrou. Para celular, React Native com Expo.
