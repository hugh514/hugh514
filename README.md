<table>

    <td width="58%" valign="top">
      <p>Minha irmã queria jogar alguma coisa comigo e não sabia o quê. Aí eu vi um cara que tinha feito um jogo na web com o celular de controle e resolvi fazer o nosso.</p>
      <p>O jogo roda no PC e aparece na TV. Cada pessoa abre uma página no celular, que vira joystick, pelo Wi-Fi de casa. Não precisa instalar nada no celular nem ter internet. São 80 minijogos para 2 a 4 pessoas.</p>
      <p>Feito com three.js e um servidor Node que conversa com os celulares por WebSocket. Dá para <a href="https://github.com/hugh514/minijogos-de-sofa/releases/latest">baixar para Windows</a> e jogar, ou ver o <a href="https://github.com/hugh514/minijogos-de-sofa">código</a>.</p>
